# Site data

`restaurants.json` and `hotels.json` feed the Restaurants and Hotels pages. The `*.example.json` files are schema samples only and are not loaded by the site.

## Hotels

Hotels are unique, independent stays only. Do not add chain hotels (for example Hampton Inn or other branded chains). Entries use the same schema as restaurants: `name`, `city`, `region`, `country`, `lat`, `lng`, `address`, `website`, `sources`, `listed_as`, `location_note`, `teddy_note`, and `visited`. Looked-up facts include a `sources` list. Leave `teddy_note` and `visited` blank until Teddy provides them. Do not invent names, dates, or addresses.
